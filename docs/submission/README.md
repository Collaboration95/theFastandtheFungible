## Rebuild the deck

```sh
ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci    # fonts come from @fontsource-variable
node scripts/facts.mjs                    # refill every number from facts.json
node docs/submission/deck/export.mjs      # PDF here + PNGs in scratch/deck-png/ to look at
node docs/submission/deck/export.mjs --refresh-shots   # also re-capture slide 10 + README hero from one hosted run
node docs/submission/deck/export.mjs --replay-shots    # offline fallback: the same shots from the /demo/ replay
```

The export refuses to replace the PDF if a fact marker is stale, if `{{`
appears in the HTML, the rendered slides or the PDF text (checked with
`pdftotext` from poppler), if an image is missing, if the PDF's page count
differs from the slide count, or if any slide's content overflows its
1920 × 1080 frame. `--refresh-shots` runs `deck/hosted-shots.mjs`: one visitor
question (an XRPL preset) on the live hosted demo, XRPL Testnet test funds within
the demo's caps, no deployment change. It writes `deck/assets/ux-answer.png`,
`ux-payment.png` (2×, light theme), the README hero `docs/media/readme-answer.png`
(1440 CSS px wide at 2×), `shots.json` (labels, question, transactions) and the run's
own exported `receipts.json`, so the README, slide 10 and the release acceptance all use
the same hosted run. `--replay-shots` is the offline fallback: it serves the `/demo/`
replay build of the current app on an ephemeral loopback port, replays the recorded
key-reveal Testnet run (`demo/traces/UC3-key-reveal.json`, fictional writers) and
blocks every outside request.

The visual system follows [UX-DIRECTION §5](../design/UX-DIRECTION.md#5-visual-system):
ink on paper, Geist only, mono for hashes and commands, sentence case. The
pixel agent on slide 1 is cut from
[`design/character/sprite-sheet.png`](../../design/character/sprite-sheet.png)
at integer scale and shows a real state (verified). Every slide names its
sources on its bottom line; speaker notes (`<aside class="notes">`) are never
printed. The site's [/slides/](../../site/slides/index.html) is the 10 Oct AI
Tinkerers talk, not this deck; it links here instead of mirroring it.

## Facts discipline

- Use only merged facts, each with its date and label: **XRPL Testnet**
  (validated transaction, no real value), **simulated** (offline rail),
  **fixture** (substituted model or research), **fictional** (the demo's research
  writers and corpus), **team-authored** (two paid writers of our own notes and sourced
  explainers, plus free Open Records; three accepted operator-issued Testnet Credentials,
  identity only, not independent supply), **TEST-SGD** (our Testnet IOU,
  stand-in for RLUSD).
- The hosted app is a **shared XRPL Testnet sandbox, open 13–19 Nov**, with no
  real value and per-visitor caps. Call it that; never "live service" or
  "production". The `/demo/` page is a replay of a recorded Testnet run;
  `/ledger/` is a static page that re-checks hashes read-only.
- The held-out numbers always carry their scope: the blind v5 bank ran once on XRPL
  Testnet with **fixture research and decision models and answers written offline**.
  The hosted sandbox writes its answers live (DeepSeek) and decides purchases with the
  rule-based model; that is not the held-out measurement. Never mix the two.
- Counts are query-defined and dated (PRs merged into `main` since 21 Sep, at a
  named commit). Never type a count that [facts.json](facts.json) has.
- At SingHacks (event build `e16435a3`, 19–20 Sep) a language model proposed each
  purchase and a person approved every quote; payment was a fixture by default.
  The 7 Sep `hackathon-baseline` tag had no approval step. Never say today's
  product asks a person to approve each purchase: policy code buys within the
  budget after one plan confirmation.
- Timings are single measurements on one Mac unless stated. Say so when asked,
  and keep the misses: <!--f:try_misses-->2 of 4<!--/f--> cold `try` runs overran 90 s.
- The 93.15% quality number is LIVE decisions on a fixture corpus with
  simulated payments (3 Nov). Quote it only with its caveats
  ([qa-prep Q19](qa-prep.md#19-does-it-actually-buy-the-right-things)). The
  80.05% and 52.9% → 40.7% figures are historical.
- After any new measurement (for example the blind v5 bank): commit its
  evidence, run `npm run site:progress -- --at origin/main && node scripts/facts.mjs`,
  re-export the deck. The [tracker](../SFF-PUSH.md) records what changed.
