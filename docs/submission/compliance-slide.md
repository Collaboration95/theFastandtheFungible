# Compliance on the deck

Policy-only spending, per-question budgets, hash-chained audit history, ledger
anchors and offline receipt verification make the spending path inspectable.
Accepted operator-issued Credentials and an operator-issued Permissioned Domain
support identity only. Regulated mode is available as a mode: credentialed writers only,
a pinned OFAC XRP address screen and audited zero-charge refusals. It is optional and off
on the hosted demo. [Compliance map](../COMPLIANCE.md).

Deployment limits belong in the deck’s single closing Status and limits slide and
in [prepared answers](qa-prep.md#22-is-it-ready-for-regulated-deployment).
