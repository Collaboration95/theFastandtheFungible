# Recording ResearchAgent

Run `make record OFFSET=300` and open the printed URL ending in `?record=1`. Each launch uses new temporary fixture ledgers, fixture providers, simulated settlement and stage pacing; it never resets another lane's data. Stop with Ctrl+C to remove the temporary store. Record mode fixes the UI defaults and event dwell times, hides presenter controls, incidental notifications and scrollbars, and keeps the header environment indicator visible. `make clip UC=UC2` starts its own servers on OS-assigned ports, drives the palette → question → clarification → plan → paid, cited answer with Playwright, and saves an 18–20 second `clips/uc2-YYYY-MM-DD.webm` plus MP4 when ffmpeg is installed. Use `VIEWPORT=1920x1080`, `1280x800` (default), or `1080x1350` for a 4:5 composition. Clips are local and gitignored. The source trace and reveal intervals repeat; browser scheduling and video encoding can vary by a frame, so this is not a claim of bit-identical video. The rail, citations and budget rules are unchanged.

The two views are Run (⌘1) and Writers (⌘2). Use Ctrl on other systems. ⌘K opens searchable commands, ⌘N starts a new question, `/` focuses the question, ⌘Enter submits or starts the five-second plan, ⌘. stops further buying, Esc closes the top layer, and `?` opens shortcuts. The existing `.` presenter and `W` Show Work keys remain; presenter controls are hidden while recording. History stays in the sidebar and recent runs are palette commands; Wallet and ledger stay under Show Work. The palette's MCP command uses the local clone and explicit S$2/query and S$5/day human caps.

`npx playwright test` runs against a production build on ephemeral ports. The performance test writes `.playwright/evidence/perf.json`: initial gzipped JS (<170 KB), launch to editable question (<2 s locally), p95 keyboard input to paint for palette and view switches (<50 ms), and CLS across the full mounted UC2 replay (<0.02). These are local fixture measurements, not live-provider latency or Testnet results.

`Start now`; keyboard shortcuts and fixture-only isolation are unchanged.
