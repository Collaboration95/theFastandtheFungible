## Phone publishing

Enable `WEB_PUBLISHING=on` in the engine and publisher, with the same private `OPERATOR_TOKEN` (at least 24 characters). Default: off. A note is pending until the operator approves it in Writers → Operator review. `AUTO_APPROVE=on` (default off) approves pre-checked notes after `AUTO_APPROVE_SECONDS` (default 5, range 1–3600). Keep auto approval off for public unattended use.

The form accepts 150–3,000 words, at least four paragraphs, a 3–100 character title, 1–8 topics, a price from S$0.01 through the existing per-source cap (S$1.00), and an optional display name. Public metadata cannot share eight consecutive words with the paid body. Prechecks reject common secrets, XRPL seeds, checksum-valid BIP39 recovery phrases of 12–24 words, identity/payment numbers, contact details, repeated text, common spam, active HTML, more than three links, and normalized duplicate bodies. These heuristics assist human moderation; they cannot establish factual accuracy, consent or universal PII removal.

Queue, rate limits, status capabilities and private signing material are persisted beside the publisher journal in `web-publishing.db` (0600). There are at most 1,000 retained submissions and ten attempts per minute globally. Operator requests use `X-Operator-Token`; tokens are compared in constant time, retained only in operator UI memory and never logged. Private status uses a random capability saved in the writer's browser. A bookmarkable private link carries it in the URL fragment, which is not sent in HTTP requests; the status request carries it in a header. Neither public status nor search returns body text or signing material. Failed publishing preserves its key and can be retried by the operator. Restart restores live notes and returns interrupted approvals to pending.

New accounts use the existing Testnet funding helper. Pasted payout addresses require a matching operator-held signing key, configured privately as an `XRPL_PUBLISHER_*_SEED`. An arbitrary unsigned address cannot meet the existing wallet-bound manifest contract. The UI explains this before submission; browser seeds are rejected. Accounts created by the service are custodial Testnet payout accounts.
