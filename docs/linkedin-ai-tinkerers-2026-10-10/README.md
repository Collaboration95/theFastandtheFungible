# AI Tinkerers Singapore — LinkedIn post working folder

Working context for the October 10, 2026 AI Tinkerers Singapore demo post.

This folder is a pre-publication workspace. It deliberately separates:

- facts captured from the event page and repository;
- recommendations for making the post useful to builders; and
- claims that still need human confirmation before publishing.

## Files

- [`context.md`](context.md) — event brief, demo guidance, project facts, and uncertainty log.
- [`post-brief.md`](post-brief.md) — audience, narrative, reader takeaway, and visual/CTA plan.
- [`draft.md`](draft.md) — a publishable draft with a homepage-link placeholder.
