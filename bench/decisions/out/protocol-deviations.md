# Protocol deviations and implementation corrections

The pre-baseline decisions are in preregistration.md (commit 9eede4d). None of the following changes production files or deployment defaults.

- The exact filename supplied in chat was absent. The matching task brief was found in the existing scratchpad under `decisions-vs-clef-prompt.md` and used as the research specification.
- The isolated worktree is in the allowed temporary directory, on the requested branch. The main checkout's uncommitted UI work remains untouched.
- Sol-generated structured specs and deterministic realization replace DeepSeek generation, as explicitly allowed in the latest user instruction. DeepSeek performs the independent 20% audit instead. Evaluated Luna is not a generator or labeler.
- The generated library contains 686 article IDs, of which 646 are used by scenario candidates/read sources and 602 have distinct realized bodies. Counts do not imply 686 independent prose observations. There are 160 scenarios but only 70 topic families (42 dev, 28 test). CV and bootstrap cluster by family, keeping clean and attack twins together.
- An attempted launch found that the dataset builder had just added the requested group/trust plumbing. The test-lock check aborted before any baseline call. After the worker confirmed the dataset final, the lock was rewritten before the successful baseline. The final test-array digest is in test-lock.txt. No labels or scenario text change during model tuning.
- Test baseline is deliberately postponed until all tuning choices are frozen. This resolves the brief's conflict between running test in Phase 2 and never viewing it during tuning.
- The instruction search uses coherent evidence-focused question bundles, with a historical round-only wording screen; it does not independently optimize every candidate question in separate calls. Context/history screens use four dev scenarios per domain; complete evidence/batch configurations use all dev. This is a bounded engineering experiment, not an exhaustive prompt optimization.
- Dev-only promotion: the history and context screens showed promising results, so all three screened configurations were extended from 28 to all 96 dev scenarios for every arm before freezing. All seven configurations are eligible only with complete dev coverage. This spends the same configuration/sample budget on every arm and avoids choosing a winner from a small screen. Cached unchanged questions are reused. No test model outputs exist at this amendment.
- The initial external quota block interrupted that promotion: Cloudflare returned HTTP429/code4006 explicitly saying its daily free allocation of 10,000 neurons was exhausted and a Paid plan was required. Its calls were stopped and a persistent local circuit guard prevents further uncached calls. No plan upgrade or alternate credentials were used at that stage; the later user-authorized Flash resumption is recorded below. Both Clef arms retain four complete 96-scenario dev configurations; incomplete context/history screens cannot win. Luna completes all seven. Configuration parity consequently does not hold beyond the first four complete configurations. At that stage, Cloudflare held-out, operational and stability results were unavailable and were never filled in with fixture predictions. This makes the overall cross-provider study partial; the switching rule cannot certify a challenger.
- The latency ceiling is shadow-measured: calls can finish up to 20 seconds so raw latency is visible; values after 3 seconds are failures for the production-policy replay. No hidden retry erases a failure. This is not a measurement of an actual network abort at 3 seconds.
- Cached responses may be reused across identical twin inputs. Cached/warm round wall time is not treated as an uncached round measurement. Cache-hit counts were added before tuning; initial baseline reconstruction uses unique request keys. Per-call distributions deduplicate cached keys.
- Before any held-out model evaluation, an isolated operational pass was added: one frozen arm at a time on the 28 clean held-out topic families, a fresh replicate namespace, and no paid-audit calls. This separates actual single-round topology latency from cross-arm contention. It does not select new prompts or thresholds. Both concurrent final timings and isolated timings remain visible; the small tail sample is a limitation.
- Paid requests complete asynchronously. Analysis matches predictions to their exact request key (or legacy request passage content), not completion-order indexes. This correction changes no labels or raw responses.
- The new corpus includes 119 candidate occurrences sharing an eight-word public-preview/body run. They are invalid evidence for the production abstract-leak checker. Bodies remain excluded from public model states; no existing leak test or threshold is relaxed. The frozen short synthetic fixtures are not proposed for production deployment.
- Regression fixtures reproduce actual source metadata and story-bible questions, not live search, payment, proof, refund or calibration trajectories. Their label oracle selects Fab Floor initially in UC3 whereas the demo story expects AlphaLeak. Both comparisons must be shown; oracle agreement must never be labelled a complete UC3 demo pass.
- The 40 inspections are an AI author audit, not human or independent review. Thirty items remain explicitly unreviewed by a human. DeepSeek agreement is reported separately. Its auditor permits a partial category whereas the constructed relevance label defines partial coverage as negative; this stricter-label mismatch is visible in the audit.
- Stability is reduced to 24 dev items with five replicates, plus three choice-order permutations. The cost cap remains stricter than requested. Token estimates for provider failures are conservative bounds, not claimed invoice charges. DeepSeek uses peak uncached pricing as an upper bound, ignoring cheaper cache/off-peak rates.
- The legacy provider enum has no OpenAI member. Luna's research adapter satisfies the unchanged interface internally while all artifacts explicitly identify the real arm; it is never wired to the production UI or wallet.
- Static lint exception: heterogeneous raw-provider/fixture plumbing under bench permits explicit dynamic types. Production input schemas, budget/cap behavior, unit checks and all five hard gates remain unchanged. No production test is removed or weakened.
- Publication scans check every configured key/token/seed value on original file bytes. The literal key-prefix scan initially rejected innocuous synthetic publisher IDs and one ordinary English phrase. Only these reviewed exact forms are allowlisted for the prefix scan; actual credential-value checks remain unconditional. No secret was staged or uploaded.

- The report adds baseline-wording robustness diagnostics separately from final-config quality. Identical Luna repetitions were stable, but cyclic originality options changed probabilities; this is not claimed as a measurement of the tuned batch prompt.
- A guarded Cloudflare-only dev-completion command was implemented for a possible billing resolution. It refuses any existing Cloudflare held-out files, requires the originally planned seven full dev configurations without quota rows, preserves the original frozen Luna/Fixture entries, and archives the first freeze. It was not used for this publication.
- Tuned policy replay keeps the explicitly selected arm threshold when falling back to Fixture. Production fallback can use its own fixture threshold. This research difference affects failure behavior and is not silently represented as production equivalence.

- After Luna held-out evaluation, the user explicitly supplied a second-account token and authorized resuming Clef-flash only. The frozen Flash evidence prompt, calibration and 0.38 threshold were preserved; incomplete dev screens were not promoted. Full-size Clef remains blocked. New requests use one in flight and at most 50/minute, with immediate quota circuit checks after admission. This introduces an account/time/limiter difference and does not restore full tuning parity. Historical quota failures remain in their original evidence.

- Final Flash evaluation completed on the explicitly authorized second account with its original frozen four-configuration winner. Luna used seven dev configurations; both winning configurations were among the common first four, but search-budget parity was not restored. Operational Flash pacing is one in flight/50 RPM versus Luna two/below-150 RPM, so cross-arm round wall-time ratios are not intrinsic model-speed comparisons. Raw request latencies are separated.
- Individual attacked fixtures can have positive value lift even when their average is negative. Twin resource IDs also differ, so this is not an isolated text-substring intervention. Neither result is a proof of injection immunity or a replacement for deterministic spending authorization.
