# FairCut media provenance

The audiovisual fixtures in this directory are generated locally by
`scripts/generate-media.sh` using FFmpeg's `color`, `drawbox`, `aevalsrc`, and
`amix` filters. They contain no third-party recording, composition, voice, or
brand asset. The three previews are synthetic tones with intentionally
different timing/energy envelopes; the clean master is a higher-resolution
synthetic tone delivered only through the protected server route after the
fixture purchase state reaches settlement simulation.

This is a team-created fixture record, not a C2PA cryptographic manifest. The
UI labels it `Signed provenance fixture · C2PA unavailable` and explicitly states that
provenance assertions do not prove copyright ownership, consent, or authority
to license. Plain SHA-256-style identifiers are labelled as asset digests, not
ISCC values.
