# Two-week demo backlog

GitHub Issues are the execution source of truth for the Builders & Brews
demo-polish sprint. Work the `ResearchAgent — Two-Week Demo Polish` project in
dependency order, starting with RA-03 (canonical reset), then the ready P0
issues. Do not begin blocked hosting work until a deployment account is
authorised.

The scope is a reliable, autonomous fixture demo: one scenario, a
pre-authorised mandate, explainable buy/skip/block decisions, exact evidence
spans, a safe receipt export, and optional managed hosting. AWS
standardisation, real publisher data, authentication, Docker, and live-source
expansion are out of scope for this sprint.
