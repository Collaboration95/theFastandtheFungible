# Local demo foundations backlog

GitHub Issues are the execution source of truth for the current local-first
sprint. Work `ResearchAgent — Local Demo Foundations` in dependency order,
starting with LDF-01 (fixture/source-policy truth) and LDF-03 (the evidence
workspace visual foundation).

The quality gate is a truthful, repeatable local flow: one canonical question,
clean fixture state, a usable evidence workspace, visible agent constraints,
and cited conclusion changes. Hosting, domains, AWS, real publisher data,
authentication, Docker, and live-source expansion are deferred until this
local walkthrough is solid.
