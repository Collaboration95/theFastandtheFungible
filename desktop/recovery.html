Common causes

This screen does not know which one applies. Start with Settings.

  • Missing keyAdd the provider key under Models in Settings, then retry.
  • Locked KeychainUnlock the macOS Keychain and allow access, then retry.
  • Engine timeoutRetry the engine. If it repeats, check Settings, or use the offline demo.
  • Port conflictQuit the other app using the MCP port, then retry.
