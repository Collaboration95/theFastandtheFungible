Does the RLUSD issuer allow escrow?

AllowTrustLineLocking is the one issuer permission flag blocking RLUSD token escrow in our recorded Testnet preflight. This check reads today’s validated AccountRoot; it does not submit a transaction or connect a wallet.

If off, tokens from that issuer cannot be locked in escrow. If on, that permission is enabled; amendment support, trust lines, freezes and other transaction rules still apply.
