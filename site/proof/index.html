Proof you can inspect

Every claim has a boundary: recorded Testnet transactions, local measurements, or simulated fixtures. None of these is a mainnet release.

Follow the money

Open the Testnet ledger to re-check the recorded transaction hashes against public servers. On mobile, each record keeps its explorer link and validation result together.

Verify an answer independently

Install the verifier, export receipts from the app, then run python -m researchagent verify answer.json --ledger. Verification checks receipts and cited content; it does not establish the truth of every source sentence.
